# Partnership & Collaboration Logos Directory (`/public/logos`)

Place your custom partner, client, and collaboration logo image files in this directory.

### Supported File Formats:
- `.png` (recommended, transparent or dark background)
- `.svg`
- `.jpg` / `.jpeg`
- `.webp`

### Default Logo Files:
- `logo.png` — Primary DZt / Portfolio logo (accessible via `/logos/logo.png` or `/logo.png`)
- `partner-1.png` to `partner-6.png` — Additional partner / client logos

Any files placed in `/public/logos/` are automatically served statically at `/logos/<filename>` by the application.
